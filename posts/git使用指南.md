# git配置指南
git在程序员的日常工作中必不可少，很多git命令已经烂熟于心，但是git的配置往往只配置一次，等下次用的时候就忘得差不多了，因此特意写了这篇文章用来在每次配置的时候作为参考。

## 配置git的用户名以及邮箱
当下载并安装好git后，第一步就是配置git的用户名以及邮箱，所以要使用如下两个命令进行配置
```bash
# 配置全局git用户名
git config --global user.name "你要设置的用户名称"
# 配置全局git邮箱
git config --global user.email "你要设置的邮箱地址"
```

## 生成私钥/公钥对
当设置好git的用户名和邮箱后往往还需要生成私钥/公钥对用来配置远程代码仓库的权限（如gitlab、github）。可以使用如下命令生成私钥/公钥对
```bash
ssh-keygen -t ed25519 -C "你的邮箱地址"
```
主要是使用 ``ssh-keygen`` 命令来生成密钥对，网上还有许多不同的写法，主要是 ``ssh-keygen`` 命令后面的参数不同，上面的参数是git推荐的写法，建议有限使用。下面给出了上述命令的详细说明。

1. ``ssh-keygen``
	- 生成私钥/公钥对的命令。
2. ``-t ed25519``
	- ``-t`` 是 "type" 的缩写，用于指定生成密钥对的算法类型。
	- ``ed25519`` 指定生成密钥对算法的名称，这是一个基于椭圆曲线的非对称加密算法。
	- **为什么选择** ``ed25519``
		- **安全性高:** 在当前的技术条件下非常安全。
		- **性能好:** 生成签名和验证的速度非常快。
		- **密钥短:** 生成的密钥文件比传统的 RSA 密钥小很多，更方便管理。
		- **现代推荐:** 目前被广泛认为是生成新 SSH 密钥的首选算法。
3. ``-C "你的邮箱地址"``
	- ``-C`` 是 "comment" 的缩写，用于为密钥添加一个注释。
	- ``"你的邮箱地址"`` 这是注释的内容。
	- **注释的作用是什么？**
		- **标识**: 这个注释会被嵌入到生成的公钥文件的末尾。当你在服务器上查看授权的密钥列表时，这个注释能帮助你识别这个密钥是谁在哪台机器上生成的。
		- **最佳实践**: 通常使用你的电子邮件地址作为注释，这是一种约定俗成的做法。例如，在 GitHub 或 GitLab 上，它会显示是哪个邮箱对应的密钥。
